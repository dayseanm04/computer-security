# Secure Email Configuration and Confidential Mode (Gmail)

## Overview
This lab demonstrates how to use Gmail’s confidential mode to send secure emails. The goal is to protect sensitive information by restricting access, configurr expiration dates, and requiring a passcode.

Email by default does not provide strong privacy protections. This feature adds an extra layer of security by limiting what recipients can do with the message.

---

## Objective

- Configure Gmail confidential mode
- Send a secure email with restrictions
