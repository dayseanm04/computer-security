# Secure Email Configuration and Confidential Mode (Gmail)

## Overview
This project demonstrates how to configure and use Gmail’s confidential mode to improve email security. The lab focuses on protecting sensitive information by applying access controls such as expiration dates and SMS-based passcode verification.

The goal is to show how built-in security features in modern applications can reduce the risk of data exposure and unauthorized access.
